ERPNext for Outlook

Link emails to Opportunities, create and assign them, parse items, and put the Opportunity number in your replies.

Download the add-in file

Install (once)

  1. Click Download the add-in file above and keep the file erpnext-opportunities.xml.
  2. In Outlook, open the add-ins page:
    • New Outlook for Windows / Outlook on the web: go to aka.ms/olksideload.
    • Outlook for Mac: Get Add-ins (the … menu on an email, or the toolbar).
  3. Choose My add-ins → Custom Add-ins → Add a custom add-in → Add from file, pick the downloaded file and confirm.
  4. Open any email, click ERPNext Opportunities (under Apps or the … menu) and Sign in to ERPNext with your usual ERPNext account.

Good to know

  • Updates arrive automatically — you install this file only once.
  • When you reply or write an email, the same button lets you add the Opportunity number to the subject.
  • Use Add from file, not “Add from URL”.

Add-ins need the new Outlook for Windows, Outlook for Mac or Outlook on the web. If you don't see “Get Add-ins” in classic Outlook, switch to the new Outlook.
