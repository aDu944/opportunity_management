# Team Inbox web build

Everything in this folder is generated by `mobile/tool/build_inbox_web.sh`
(Flutter web, `lib/main_inbox.dart`) in the ALKHORA-ESS repo. Do not edit by hand.

Commit the folder as a whole after every build — stale or missing files break
the app. It is served at `/assets/opportunity_management/inbox/`, and `/inbox`
redirects here (`website_redirects` in `hooks.py`). The `index.html` in the repo
before the first build is only a placeholder.
